Data Analytics Projects

This repository contains end-to-end data analytics projects focused on healthcare performance and macroeconomic trends. Both projects utilize Power Query for data cleaning and transformation, along with Pivot Tables, Pivot Charts, and visual dashboards for data analysis and storytelling.

---

End-to-End US Healthcare Analytics

Overview
An end-to-end analytics project analyzing US healthcare data to extract key operational insights, identify performance trends, and support data-driven decision-making.

Key Steps & Methodology
Data ETL & Transformation: Cleaned, formatted, and structured raw healthcare datasets using Power Query.
Data Summarization: Built dynamic Pivot Tables to aggregate patient metrics, operational costs, and performance KPIs.
Visualization: Designed interactive Pivot Charts and graphical dashboards to highlight key healthcare trends and insights.
Recommendations: Delivered actionable strategies for operational efficiency and patient care optimization based on visual findings.

---

CPI Inflation Analysis

Overview
An analytical study examining Consumer Price Index (CPI) metrics and inflation trends across key categories to evaluate purchasing power and economic changes over time.

Key Steps & Methodology
Data Prep & ETL: Extracted and cleaned multi-year economic CPI datasets using Power Query.
Analysis & Segmentation: Aggregated inflation indicators and category-wise price changes using Pivot Tables.
Graphical Charts & Dashboarding: Developed graphical trend charts and visualization views to highlight historical inflation spikes and steady growth periods.
Economic Insights: Provided key recommendations and summary insights detailing the impact of shifting CPI trends.

---

Tech Stack & Tools
Data Cleaning & ETL: Power Query
Analysis: Excel Pivot Tables
Data Visualization: Pivot Charts & Graphical Dashboards
